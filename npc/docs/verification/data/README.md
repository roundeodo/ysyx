# 研究比较摘要

本目录只发布精简比较表、配置、来源和工具元数据。它们记录已完成的实验，不是完整
仿真归档。原始日志、逐条 trace、波形、软件镜像、网表、快照压缩包和完整日志索引不上传。

各子目录文档提到的 `evidence/`、`raw-log-index.json`、`log-index.json` 和原始目录位于
测量时的原工作机；2026-09-24 已按要求清理原始 result。这些路径是历史来源，不能当作
当前本机或远程现存文件。需要这些产物的 `--check-only` 审计仍要求完整旧归档。新实验从源码构建，见
[研究入口](../../learning/FRONTEND_RESEARCH_INDEX.md)。
