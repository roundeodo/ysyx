# 单级 EX 的时序修复

用户明确要求最终单级 EX 且通过 700 MHz，保留结果级不作为最终方案。

第一组 RTL 修复不加状态、不改变交付时间：
- 返回侧 B/J 立即数与目标加法并行，指令类型在加法后选择目标。
- 方向策略不等待 opcode 识别；条件分支类型仍在 taken 输出处门控。
- 真实/预测下一 PC 的比较并行计算，再选择一位 mismatch，消除宽 mux 后比较。

这些是保持算法与协议不变的组合路径重构，必须重测面积/STA并通过取指恢复测试。
700 MHz 为验收目标；未通过不切换默认配置，也不能用运行在非法频点的功能仿真声称性能。

第二组修复：阻塞 I-cache 响应身份来自保持的 S1 请求；数据/错误的来源由已寄存的 miss 占用状态选择，VALID 仅控制响应交付。新增断言验证 S1 保持、miss 响应身份一致及响应有在途所有者。无新增状态或等待。
