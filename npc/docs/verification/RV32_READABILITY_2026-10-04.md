# RV32 命名与电路阅读顺序复查

范围：`ysyx-workbench-rv32-interview`，分支 `branch-v3-20261001`，基点
`99022745468c6a3d0def7273424cb82163ee8223`。开始时主仓库无未提交源码；
`am-kernels`、`ysyxSoC` 已有子模块改动，本轮未修改它们。

## 结论与改动

逐文件检查 `vsrc/riscv32` 全部 74 个文件，包括未启用的预测器、历史实验、仿真模型和
filelist。主流水线、cache 和 AXI 状态机已有明确分组，保留其电路和模块边界；
后续增加的前端实验代码仍有命名与排版缺口，不能说此前已全部符合规范。
本轮修改 9 个前端 RTL 文件，另修正 EXU、regfile 的旧模块名注释。

- TAGE/SC/Loop：明确查询/训练上下文、provider/alternate 方向、SC 求和、Loop 迭代数；
  区分 `_vector`、`_array` 和 `_index`。保持历史、并行查询、方向汇合、训练反馈的分组。
- I-cache 替换：`access_set_index`、`access_way_index` 表达编码索引；
  `segment_start` 表示跨行访问段开始，避免与 AXI burst 混淆。
- IFU：按返回指令识别、可选 RAS 保持、直接目标、下一 PC 比较、响应组装标明功能。
  RAS 保持分支内的两条组合读/直通赋值移到寄存更新之前，便于按电路阅读。
- BHT、BTB、压缩 BTB、小型 TAGE、方向选择和直接目标模块：条件与赋值分行，
  修正循环体缩进、长表达式换行与字段对齐。同步更新测试中的函数调用名称。

未新增或删除寄存器、等待、旁路、运算和接口；没有改变算法、配置默认值或握手条件。
历史实验保留原入口与用途注释，不因当前未实例化而删除。

再次复核确认此前 74 个文件的哈希一致；补齐替换策略的一处同行 `else` 赋值，
整理 TAGE 折叠历史与 SC 阈值比较的换行，并注明查询路径和训练状态的边界。
补改仅含空白及说明注释；74 文件词法核对、整核 lint 再次通过（保留既有警告）。
71 个 RTL 文件扫描未发现同行 `if/for` 控制体；其余为头文件和 filelist。
本次未重复运行功能回归，上一轮功能结果见下表；最新源码哈希见
[第二次核对结果](data/rv32-readability-20261004/recheck-equivalence.json)。

## 应怎样读源码

| 范围 | 阅读顺序 |
| --- | --- |
| 组合执行/译码 | 输入字段与选择 → 并行运算 → 结果/异常汇合 |
| 缓冲/流水寄存器 | 当前输出与容量 → 接收/保持/清除条件 → 状态更新 |
| cache/LSU/AXI 状态机 | 必要派生条件 → 组合输出 → 组合下一状态 → 时序更新 |
| 预测器/替换表 | 查询路径与训练反馈分别成组；各组标明读取及写入的状态 |
| 顶层与仿真 | 按接口连接组织；被动观察器与可综合电路分开 |

并行电路、反馈和状态所有权不强行排列成串行路径；章节顺序不代表新增流水级。
逐文件的“修改/检查后保留”及原因在
[检查清单](data/rv32-readability-20261004/file-review.csv)，当前前端说明在
[数据流与源码顺序](../microarchitecture/FRONTEND_REWRITE_DESIGN_RECORD.md)。

## 验证结果与边界

配置为 `rv32-balanced`；精确参数由保留的命令和源码哈希确定。

| 检查 | 结果 |
| --- | --- |
| 74 文件词法比较 | 去除普通注释/空白、应用显式重命名后一致；仅允许 IFU 两条独立连续赋值移动 |
| Verilator 整核 lint | 通过 |
| Yosys/Slang 整核读取与 hierarchy 检查 | 通过；这不是映射综合或 STA 签核 |
| taken-loop 取指接口 | 100 次交付通过，目标查询间隔 1 拍 |
| FENCE.I/整核 cache 恢复 | 84 项通过 |
| 精确异常 | 40/40 通过 |
| 缩放 TAGE/SC/Loop 软件模型对照 | SC/Loop 四组合 × 三种种子 × 3000 周期；预测、查询快照、逻辑状态全部一致 |
| I-cache policy13 与 C++ 模型对照 | 2/4/8 路三种几何通过，含同拍查询/更新旁路 |
| 旧预测器契约测试的原适用配置 | 10 组、120000 周期通过；静态策略与早期目标关闭 |

**发现的旧测试缺口：** `test-predictor` 直接用于 `rv32-balanced` 时失败。
在修改前的 `9902274` 快照中复现同一时刻、同一 PC、相同 expected/actual 的失败。
旧模型未填 `raw_direction_counter`，也未建模弱态 BTFNT 选择，却比较整个预测包。
因此不能把该测试记为 balanced 配置通过。本轮保留失败日志，未改参考值、屏蔽字段或断言；
仅在其原适用配置上验证现有契约。balanced 的取指、恢复及异常测试结果独立列在上表。

本轮是源码可读性整理，不作完整功能重新验收，也未重跑 MicroBench、映射综合/STA。
词法检查不是形式等价证明；它约束本轮改动范围，功能回归补查命名绑定和接口行为。
不报告新的面积、频率或 IPC，不以本轮解析通过替代历史 PPA 测量。
