## 重叠收益与代价

- 同镜像混合 FU 定向程序：原后端 6649 周期，新 ROB4 为 5988 周期，均退休 1961 条，减少约 9.94%。
  观察到除法在途时派发 390 次、提前 load 129 次、同拍多 FU 完成 128 次，证明独立 FU 重叠确实发生。
- 标量 int8 dot/normalize 的 RV32IM 镜像：原后端 192451 周期，新 ROB4 为 191851，均退休 151125 条，
  仅减少约 0.31%。这两项采用 standalone flat memory，不能当作 SoC 原生计时或 train 结果。
- 在 380 MHz 的 test 中，ROB4 打开 load overlap 相比关闭时 Total 减少约 0.98%、Scored 减少约 1.65%，
  但仍慢于原后端。ROB8 相比 ROB4 只减少约 0.13% Total 周期，不能抵消容量和时序代价。
- ROB4 的 test 整程序记录 1094 次除法期间派发、19036 次提前 load、2513 次多完成；相对于 523371 次
  派发，独立除法重叠机会较少。RAW、顺序发射队首阻塞和单请求 LSU 仍限制可隐藏的等待。
  不用旧后端专有的 issue-slot 分类替代新后端的精确停顿归因。
- 同频原后端和 ROB4 都有 D$ refill 11934 次/47736 words、writeback 8010 次；I$ 完成 refill
  从 1984 到 1987。它们是**整程序流量代理**，不与 Total 窗口混算，也不代表功耗测量。

## 电路取舍与时序

保留了 ROB 满出入同拍、ID/EX 出入同拍、完成当拍前递、当前 ALU 前递、已寄存完成到退休旁路、
DIV 空输入直通/快捷结果，以及老队首正常退休后下一条 store/MMIO 当拍获得授权。
不同 ROB 项保留结果版本，scoreboard 选最近老写者，删除了初版不必要的 WAW 退休等待。

LSU 返回和刚派发的 DIV 快捷结果不能无条件组合直达退休，否则完成→异常恢复→派发许可会形成反馈。
它们写入**现有 ROB 结果存储**再退休，数据仍能当拍前递。store/MMIO 等队首是精确副作用要求。
已经握手的错误路径读必须排空；身份复用通过独立 discard 状态隔离，未堆加一套代际计数器。

ROB4 在 600 MHz 的四组最差 slack 分别为 data setup +30 ps、gating setup +21 ps、data hold +59 ps、
gating hold +94 ps。关键数据路径从指令总线响应经 I$ 返回/直通、译码与生产者选择，进入 ROB 项更新；
并不是乘法阵列本身。620 MHz 时数据/门控 setup 为 −13/−22 ps。2026-09-29 复用同一网表补测 700 MHz，
数据/门控 setup 为 **−160/−169 ps**，hold 仍为 +59/+94 ps。数据路径从 AXI RVALID 经回填响应选择、
译码、最近生产者与发射条件到 ROB 分配写入；门控路径继续经 fetch buffer 的 ready 反馈到 I$ RRIP 更新使能。
因此新增 issue 边界若仍让该 ready 链组合贯通，并不能保证消除门控违例。
补测报告位于 `npc/result/backend-rob/sta700-audit-20260929/`，未重综合或改约束策略。
本轮没有为切短这条路径盲目加独立 issue 级；后续若继续优化，应针对可用性判断和分配使能的组合链验证。

已比较并拒绝的电路：

| 候选 | 证据与结论 |
| --- | --- |
| 同名目的寄存器等老写者退休 | 700 MHz 逻辑比较中 test Total 从原后端 2220172 增到 2307346 周期；结果版本消除该等待后降到 2225912。700 仅用于这次同频逻辑筛选，不作为新后端合法频率。 |
| 把 PC+4 移到 ROB 输出端 | 120096.074 μm²/580 MHz；轻微面积收益不能抵消相对候选的频率下降，未保留。 |
| 每项完成选择改成掩码 OR | 4 项只有 560 MHz，未优于保留结构。仍然有四路独立完成端口；每项内部选择不会仲裁掉其他项的完成。 |
| 完成时重复改写 MUL/DIV 异常字段 | MUL/DIV 不产生执行异常，增加无用退休选择逻辑；最终仅 ALU/LSU 更新相关异常字段。反压下完整队首载荷稳定性断言通过。 |
| 8 项作为默认容量 | 合法频率 380 MHz、面积 128822.204 μm²，同频收益很小，拒绝默认启用。 |

一次中间综合曾给出 800 MHz/67922.568 μm²，但共享 fence 信号声明晚于 generate 引用，导致综合得到
未驱动网并错误裁剪电路。**该结果无效**，已标记、修复声明顺序并重测。测量脚本现在拒绝未驱动网、
冲突驱动和组合环的综合结果；不能把工具生成数字等同于有效硬件。

## 正确性与复现

最终 ROB4 + load overlap 完成：2803 个乘除法 oracle/DiffTest 用例、混合 FU/多结果版本检查、
40 个精确异常组合、100 个 FENCE.I/clean-error/dirty-victim/错误 taken 整核场景、定时中断与量化内核。
另有 2/4/8 项 ROB 各 10000 周期随机参考队列（反压、满队列交接、并发完成、恢复与绕回），以及
36 个恢复/LSU 延迟与访问错误组合，覆盖恢复同拍响应和取消后复用身份。
中断测试改为观察实际 FU 在途状态；恢复点用真实 RAW 依赖固定，保留精确 mepc 断言。
原后端 core/中断回归也通过。没有关闭断言、删除失败用例或修改软件期望结果制造通过。

完整定向整核回归以 ROB4/load overlap=1 为主；2/8 项通过队列随机与 native test，不声称所有参数
组合都有同等覆盖。未运行本轮完整 train、形式验证、布局布线或功耗分析。

从仓库根目录运行（输出目录使用新路径）：

```sh
make -C npc git_commit= NPC_HOME="$PWD/npc" NPC_CONFIG=rv32im-pipelined \
  NPC_BACKEND_ROB_ENABLE=1 NPC_BACKEND_ENTRIES=4 NPC_BACKEND_LOAD_OVERLAP=1 \
  NPC_ASSERT_ENABLE=1 BUILD_DIR="$PWD/npc/result/backend-check/build" build-npc
python3 npc/scripts/verify_mul_pipeline.py --simulator npc/result/backend-check/build/top_sim \
  --backend-rob 1 --backend-entries 4 --load-overlap 1 --output npc/result/backend-check/checks
python3 npc/scripts/test_backend_rob.py --output npc/result/backend-check/queue
python3 npc/scripts/test_backend_recovery.py --output npc/result/backend-check/recovery
python3 npc/scripts/test_backend_core.py --simulator npc/result/backend-check/build/top_sim \
  --output npc/result/backend-check/mixed
```

每个配置分别用 `measure_execute_ppa.py --name <名称> --output <PPA目录> --mul-pipeline 1`
加 `--backend-rob/--backend-entries/--load-overlap` 生成 `retained-legacy`、`retained2`、`retained4`、
`retained8`、`retained4-noload` 五个目录，再运行：

```sh
python3 npc/scripts/compare_backend_perf.py --ppa-root npc/result/backend-check/ppa \
  --output npc/result/backend-check/performance
```

若手动测新 ROB4 的 train，请使用本配置通过 STA 的 600 MHz：

```sh
python3 npc/scripts/run_microbench_perf.py \
  --scale train --isa rv32im --mul-pipeline 1 \

  --icache-bytes 1024 --icache-ways 4 --icache-line 32 --icache-policy 13 \
  --bht-entries 16 --btb-entries 16 --btb-ways 2 \
  --btb-policy 0 --direction-policy 0 --history-bits 4 --ras-entries 4
```
