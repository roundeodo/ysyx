# RV32IM 乘除法单元

当前实现：EXU 内的可选 RV32 M 扩展。`rv32-balanced` 仍为 RV32I；
`rv32im-balanced` 启用八条 M 指令，使用同一组缓存和预测器参数。
该迭代预设经 NanGate45 综合后完整 STA 通过 700 MHz，面积为 106,339.086 μm²。
另有 `rv32im-pipelined` 候选：乘法三拍、启动间隔一拍，除法独立迭代；
结构与边界见[乘法流水](MUL_PIPELINE_DESIGN.md)。以下描述迭代对照，不把其 PPA 套到流水候选。
当前时序见[前端优化记录](../verification/RV32IM_FRONTEND_TIMING_2026-09-28.md)，
乘除法及地址电路取舍见[执行通路记录](../verification/RV32IM_TIMING_2026-09-28.md)，

## 参考与选择

- [Ibex MULT/DIV](https://ibex-core.readthedocs.io/en/latest/03_reference/instruction_decode_execute.html)：
  ASIC 均衡实现复用 17×17 有符号乘法器和 34 位累加器，MUL 3 拍、高半乘法 4 拍；
  采用这种部分积组织，不移植其外部 ALU/中间寄存器接口。
- [CV32E40P](https://docs.openhwgroup.org/projects/cv32e40p-user-manual/en/latest/pipeline.html)：
  多周期指令保持 EX，完成时提供前递；本核沿用已有 ID/EX 与执行结果边界。
- [PicoRV32](https://github.com/YosysHQ/picorv32)：提供迭代乘除法及快速乘法选项；
  小面积的逐位乘法延迟更长，本轮不采用 PCPI 或把整个 32×32 乘法放在单拍关键路径。
- [M 扩展 2.0](https://docs.riscv.org/reference/isa/v20260120/unpriv/m-st-ext.html)：
  八条指令、混合符号高半乘法、向零取整、除零和 INT_MIN/-1 均按规范处理，不产生算术异常。

这些是公开机制的独立实现，未复制上游 RTL。参考核自身的面积、频率不作为本核成绩。

## 数据通路与状态

译码是操作编码唯一所有者，输出 `FU_MULDIV` 和语义操作枚举。EXU 选择乘除法结果，
复用已有执行结果寄存级、WB、提交和前递通路。ID/EX 在多周期期间保持 PC、操作数、
目的寄存器、异常和预测身份；MDU 不复制一份完整执行包。

乘法将操作数拆为低 16 位和带符号的高 17 位。四个部分积按低×低、高×低、低×高、
高×高依次生成；低半结果第三拍即可交付，高半第四拍交付。两种交叉部分积的进位
使用 34 位累加器保存，低 16 位借用商寄存器保存。乘法与累加写成同一表达式，
综合把累加项并入部分积压缩树；首拍累加项为零，不串联额外的完整进位加法。

除法先取绝对值，再每拍生成一位商，最后修正商或余数符号。迭代余数复用同一 34 位
累加器。试减使用独立 34 位减法器，最终商/余数单独修正符号，避免把乘法部分积、
输入选择、试减进位和余数选择串成一条路径。共享的是算法寄存器，不再共享组合加法器。
除数绝对值单独
寄存，避免每拍试减都串联一次符号变换。商 32 位、计数 5 位；无需另加结果寄存级。
一般除法用 34 拍（启动、32 次试减、符号修正/交付）；除零、绝对值被除数小于除数、
除数绝对值为 1、乘数为 0 在输入拍直接返回。没有为特殊情况加统一等待。

状态顺序：IDLE → MUL_CROSS_A → MUL_CROSS_B → 可选 MUL_HIGH，或
IDLE → DIV_STEP → DIV_SIGN。`result_available_o` 仅表示当前操作的算术结果已经可用；
EXU 再用输入 valid、操作类型及 issue_allowed 形成交付 valid。IDLE 中该信号也可能因
当前输入满足捷径而为 1，不能脱离 EXU 的有效位单独当成一条完成消息。
下游反压或暂停发出时保持最终状态和算法寄存器；握手后回 IDLE，没有 DONE 搬运拍。

## 前递、恢复与顺序

未完成的乘除法视为最近但未就绪的生产者，不能回退使用更老 WB 的同名寄存器。
最终结果可用当拍可前递给译码，不把异常/中断发出门控再串进 RAW/ready 网络。
消费者仍受 ID/EX 的 progress 和 flush 约束；只有允许交付时才会推进，不强制等到 WB。
较老访存、异常或恢复仍由现有 hazard 禁止交付。中断等待 ID/EX 排空，不越过乘除法。
较老 redirect/异常清除算法状态；非分支错误 taken 的自身恢复在交付沿触发，不能反向
组合撤销本条结果。没有推测完成队列，也不允许年轻指令绕过执行中的除法提交。

`misa.M` 随配置报告。关闭 M 时八条编码仍为非法指令，生成条件删除 MDU。
本轮只实现 RV32IM；RV64 配置保持现状，不宣称实现 RV64M。
