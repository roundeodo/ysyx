## 电路与状态

BTB 保留原 tag、目标、类型、有效位；训练来自 EX 结果交付，不新增推测状态或事务身份。
新增参数 `BRANCH_TARGET_POLICY`：

| 值 | 分配与替换 | 新状态 |
| --- | --- | --- |
| 0 | 所有已解析控制流均可分配；原轮转替换 | 无，保持基线 |
| 1 | 未命中的未跳转条件分支不分配；已有表项仍可更新；轮转替换 | 无，简单准入对照 |
| 2 | 同策略1准入；跳转且训练命中才将 RRPV 提升到0；插入2，满组按最大RRPV选择并老化 | 每项2位RRPV；替换掉无用轮转状态 |
| 3 | 同策略1准入；两路 LRU，只在分配或跳转命中时更新最近使用关系 | 复用每组1位替换指针，仅支持两路 |

策略2为基于实际目标使用的 RRIP 原型。它借鉴“复用应围绕 taken 目标需求衡量”的观察，
没有 Thermometer 的离线 OPT 温度、软件提示或 GHRP 的学习表，不称为完整论文复现。
策略1必须独立测量，避免把过滤未跳转分支的收益归给 RRIP。
两路16项BTB中，策略2用32位RRPV取代8位轮转指针，净增24位策略状态；32项时净增48位。
这是逻辑状态量，不包含选择门、缓冲及映射变化，实际成本以整核综合为准。

源码顺序对应电路：表状态 → 组合查询 → 训练索引及 victim 选择 → 写使能 → 替换状态更新
→ 同步写入。查询只读取 tag/target/kind，不经过 RRPV 或准入逻辑。
同拍查询/训练仍读旧表；连续训练读到前沿写入值。替换更新在训练路径中，不增加训练寄存级。

训练先查同 tag，再查空 way，全组有效才执行策略选择。未命中的未跳转条件分支不改变
BTB payload、有效位或替换状态；BHT 和 RAS 的训练不由该过滤条件控制。
已有表项即使本次未跳转也可更新目标和类型，但策略2/3不因这次访问提高保留优先级。

复位和 invalidate 清有效位及替换状态；invalidate 同拍禁止训练。普通 flush 只丢弃预测
响应，仍遵循原有 EX 训练契约。FENCE.I 协调、非分支错误 taken 纠正和精确异常路径不变。
所有策略只影响预测质量，不能改变 valid/ready 身份、取消已展示总线请求或产生提交副作用。

## 验证要求

独立行为模型覆盖全部策略、随机反压、查询/训练同拍、同组冲突、连续更新、flush、失效
与复位；定向检查未跳转不分配、taken 分配、空路优先及 RRIP/LRU victim 顺序。
整核用相同镜像核对校验值、退休数及退休PC/GPR结果摘要，并执行已有 FENCE.I、异常和写回恢复回归。
候选按同频周期、各自合法频率的执行时间与全核面积决定，实验参数不改变默认预设。
