# 小型历史方向预测原型

2026-09-23，实验默认关闭。沿用BHT模块与现有唯一预测响应寄存级。

## 电路与状态

参数`BRANCH_DIRECTION_POLICY`：0为原PC索引二位计数器，1为gshare，2为bi-mode；3/4为默认关闭的[小TAGE实验](TAGE_DESIGN.md)，其每表项数和快照定义见该说明。
`BRANCH_HISTORY_ENTRY_COUNT`始终计入全部二位计数器：bi-mode一半为PC选择表，四分之一为偏不跳表，四分之一为偏跳表。
`BRANCH_GLOBAL_HISTORY_BITS`规定已解析条件分支历史长度；只在无异常EX条件分支交付时移入真实方向。
查询不修改历史，没有推测检查点，也不因查询或后端等待增加周期。

查询顺序：PC及当前已解析历史 → 组合索引/并行表读 → 方向选择 → 原预测响应寄存器。
gshare将短历史异或到PC索引高位；bi-mode选择表按PC索引，两张方向表按PC异或历史索引。
选择表、偏不跳表初始01，偏跳表初始10。当前查询和同拍训练看到沿前状态，不增加EX到查询的组合旁路。

每个查询保存历史快照；bi-mode另保存所选表及该表当时的方向。快照置于`branch_prediction_t`，
沿现有IFU队列、fetch buffer、uop与EX结果载荷传递，不增加新的队列或流水级。
训练用该指令快照重建索引，读该项当前计数器做饱和更新；不得使用后来已变化的全局历史。
bi-mode只训练当时选择的方向表。所选表预测正确且与所选偏置相反时保持选择表；其余情况按真实方向训练选择表。

策略0的元数据输出恒零，历史状态不实例化，综合应删除对应载荷寄存器。策略1只需历史快照，其他两位恒零。
实际新增寄存器包括历史状态和各在途载荷中的有效快照位，不能只按表位数报告开销。

## 恢复和同拍优先级

reset初始化计数器并清历史。invalidate清历史但保留计数器，同拍禁止训练。
普通flush丢弃原查询响应和年轻流水载荷，保留已解析历史；触发重定向的有效老分支仍可训练。
历史不包含尚未解析的年轻分支，因此无需恢复推测历史。旧epoch响应由现有IFU协议排空，不能取消已展示请求。
错误路径已解析训练与原BHT训练边界相同，只影响预测质量，不允许造成架构副作用。

## 验证边界

独立参考覆盖延迟训练、连续同PC/别名训练、两表选择、饱和、历史变化后旧快照训练、初始复位、invalidate与训练同拍。
整核补随机反压、FENCE.I和错误恢复回归，核对相同软件的退休摘要与独立输出。
模型的立即训练和RTL的查询快照不同，最终选择必须依据真实周期、完整STA及整核面积。


## 大表训练数据的映射对照

固定的共享二位训练数据在小表中可直接广播；扩到512项时，当前AREA 3映射会让一个小驱动门直接驱动512个寄存器D端，出现约3 ns的电气延迟。本轮增加独立的F对照，不改变默认综合流程或RTL。

电路为原训练数据驱动门 → BUF_X4缓冲树 → 原寄存器D端。只对负载超过64的训练数据网处理，树内每级最多16个负载；训练写使能、时钟、复位、查询和恢复协议保持原连接。没有新增状态、流水级或等待。

`buffer_history_training.py`从冻结映射的JSON生成缓冲网表，归并新缓冲后逐单元核对原连接，再单独测面积及完整STA。相同频率下的RTL结果可以复用；不同频率仍按固定物理服务时间重新仿真。F与原版本分别保留，不能把映射驱动的改善记成gshare准确率的改善。结果见本轮分支历史探索记录。
