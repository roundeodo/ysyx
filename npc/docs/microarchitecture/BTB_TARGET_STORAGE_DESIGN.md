# BTB目标地址编码实验

2026-09-23，已完成RTL、回归与PPA，作为可选实验保留。默认参数为0，沿用原BTB；不增加查询或训练寄存级。

## 电路与参数

`BRANCH_TARGET_WAY_BITS`为4个8位宽度字段，最低字段对应way0。0选择原实现；非0选择
短目标实现，每个使用中的字段须为1～XLEN。只承诺2/4路、策略0/1的已测试配置。
例如两路`[16,16]`编码为`0x00001010`，四路`[8,12,16,32]`为`0x20100c08`。
宽度包含地址低两位，与论文通常扣除对齐位的统计口径不同。

每路各有独立的完整tag、短目标、类型数组；有效位和每组轮转指针独立于载荷。
查询PC同时索引各路 → 完整tag比较 → 将PC高位与该路目标低位拼接 → 唯一命中合并。
完整tag保证拼接所用PC属于同一条分支；没有新增tag别名，也没有查询加法器或间接页表。
父预测器保持原有RAS选择、目标对齐检查和唯一响应寄存器。

训练PC/target高位比较决定各路是否能表示目标；完整tag比较定位原条目。
先保留仍能容纳新目标的同tag项，否则选可用的空路，最后从轮转指针起选择能容纳目标的路。
只有替换有效项才推进指针。每路位宽在 elaboration 时固定，不为每项保存位宽字段。
统一16位是简单对照；不同位宽的路借鉴BTB-X，不声称复现其8路、RAS专用路或大核前端。

## 状态更新和恢复

训练命中但新目标不再适配原路时，先使原项无效，并在能表示新目标的路中重新分配。
若所有路都不能表示，保留为预测miss，不截断地址，不产生错误的“命中目标”。这影响性能，
不影响后端计算真实目标。含32位路的配置可以表示任意RV32目标，统一16位配置不能。
不同路不得同时保留同一PC；断言检查查询和训练匹配one-hot。

同拍查询/训练仍读沿前状态；下一周期直接见更新，不增加待写队列或旁路。
reset/invalidate清有效位及指针，invalidate压过训练。普通redirect沿用父模块的响应清除，
已接收的指令存储事务仍按epoch排空。只在有效训练沿写载荷，无效载荷不复位。
策略1只过滤未命中且未taken的条件分支；已有项更新和失配清理仍执行，BHT/RAS不受过滤影响。

## 要核对的成本与边界

每组状态位为`sum(tag_bits + target_bits[way] + kind_bits + valid) + pointer_bits`。
只节省目标位数；完整tag、比较器、训练适配比较和选路逻辑均计入整核PPA。
四路完整目标表是必须的对照，不能将关联度收益归给不同位宽；还比较同电路全32位对照。
初始基线、软件划分和实验结论见[目标预测探索](../verification/BRANCH_TARGET_EXPLORATION_2026-09-23.md)。

独立测试覆盖位宽边界、非对齐目标、同PC跨路迁移、无路可容纳、同拍查询训练、连续写、
复位、失效优先和全部公开配置。整核保持精确异常、非分支纠错、FENCE.I与错误恢复回归。
程序布局另放在64 KiB边界两侧，检查统一短目标没有仅因单一链接布局而看起来有效。

## 采用范围

U16在当前代理输入上小幅降低面积×时间，但频繁跨64 KiB调用的压力测试从455拍增至959拍。
H32能容纳任意RV32目标，却未获得足够收益抵消整核面积。两者均不默认启用；稳定配置保持
原16项两路BTB。不要只根据功能正确或当前代码尺寸，就删除完整目标配置。
