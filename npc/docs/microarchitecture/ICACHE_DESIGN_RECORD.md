# RV32 I-cache：原理与电路结构

当前实现，2026-09-19。`rv32-baseline` 为 256 B、一路、16 B/行、每次取 4 B；
参数由 [Makefile](../../Makefile) 进入 `riscv_config_pkg`。RTL 同时保留组相联配置能力。

## 查询路径

输入地址先经过 PMA 分类。请求握手沿同时采样请求身份、执行/缓存属性，并同步读出
各路 tag 和目标指令字。沿后比较 tag，命中时组合选择数据并返回；**没有独立 S2 寄存器**。
命中流可每拍接收一个请求；响应反压时，请求寄存器和阵列读输出一起保持。

不可执行地址直接返回取指访问异常；可执行但不可缓存的地址经 miss 路径发起单字读取。
可缓存地址未命中时回填整行。阻塞期间拒绝新查询，关键字提前返回不代表可以 hit-under-miss。

## 模块与状态

| 模块 | 电路与保存的状态 |
| --- | --- |
| [PMA](../../vsrc/riscv32/core/frontend/riscv32_pma.sv) | 组合地址分类，无寄存器；区域常量来自 `riscv32_addr_map_pkg` |
| [I-cache 主体](../../vsrc/riscv32/core/frontend/riscv32_icache.sv) | 对齐请求与属性；并行 tag 比较、数据选择、替换和失效控制 |
| [tag 阵列](../../vsrc/riscv32/core/frontend/riscv32_icache_tag_array.sv) | 每路/组保存 tag 与有效位，同步读出；复位清有效位 |
| [data 阵列](../../vsrc/riscv32/core/frontend/riscv32_icache_data_array.sv) | 按路和行内字分 bank，同步读出；回填写入先暂存，再于低电平写入锁存阵列 |
| [miss 单元](../../vsrc/riscv32/core/frontend/riscv32_icache_miss_unit.sv) | 一个事务上下文：原请求、替换路、可缓存位；错误累计、响应缓冲和响应已生成记录 |
| [AXI 适配器](../../vsrc/riscv32/core/frontend/riscv32_icache_axi.sv) | 单个读事务；保存地址、字数、返回字索引与事务编号 |

请求身份与同步阵列输出必须对齐，不能随意删除其中一组寄存器。数据写入暂存保证锁存窗口
内输入稳定。miss 响应“仍待接收”和“已经生成过”分别记录：前者承受反压，后者避免重复响应。

一路配置不保存替换状态；多路优先选择无效路，否则使用每组轮转指针。
替换指针在可缓存 miss 被接收时推进，不在 hit 时更新；set、tag、关键字索引从原地址派生。

## miss 怎样完成

| 状态 | 输出行为 | 转移条件 |
| --- | --- | --- |
| `MISS_IDLE` | 接受 miss 并当拍发 refill | 下级接收则等待返回，否则进入发送重试 |
| `MISS_SEND_REFILL_REQUEST` | 保持回填请求；握手时使被替换行失效 | 下级接收后进入回填状态 |
| `MISS_RECEIVE_REFILL` | 接收各字、写数据；关键字当拍直通，反压才保存唯一响应 | 末字握手后，若响应仍待接收则进入完成状态，否则空闲 |
| `MISS_COMPLETE` | 保持尚未消费的响应 | 响应接收后释放事务 |

AXI 适配器空闲时直接发 AR，受阻才进入发送状态，随后接收 R。整行访问从行首发出 INCR burst；
非缓存访问从请求字地址发出单 beat。`last_word` 转发下级 RLAST，返回顺序没有调整。
AR 接收后只推进用于选择总线数据字节位置的地址低位。

关键指令字到达当拍可交给 IFU，反压时保存，剩余回填继续；直到末字和待消费响应都处理完，才释放 miss。
只有无错误的整行回填才能安装有效 tag。若关键字交付后后续 beat 出错，已交付指令保留，
该行不安装，也不生成第二个响应。完整 beat 序列由断言检查。

## 清除与接口边界

- 请求和响应只在 `valid && ready` 时传输；反压时保持完整载荷。
- `fence.i` 停止新查询并排空旧查询与 miss；在完成握手沿一次清除全部有效位。
  有效位独立于 tag/data，不保留逐组逐路扫描状态机；请求方保持请求直到完成。
- redirect 不取消已经接受的总线事务。cache 原样返回 PC、epoch、tag，由 IFU 丢弃旧响应。
- Flash、PSRAM、SDRAM 可缓存；SRAM、MROM 走非缓存路径；MMIO 与未映射地址不能取指。

## 取舍与验证

单 miss 和同步读使请求顺序、错误处理及阵列边界清楚；代价是回填期间前端停顿。
关键字提前返回只能重叠后端执行和剩余回填，不能消除这段阻塞。
