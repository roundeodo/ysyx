# 候选研究卡

具体电路、状态生命周期和恢复优先级统一见[电路契约](../../microarchitecture/BRANCH_V3_DESIGN.md)。以下记录假设与对照，避免把来源、算法准确率和系统收益混为一谈。

| 候选 | 要修正的问题、信息何时可得 | 资源与规则 | 对照与可证伪条件 |
| --- | --- | --- | --- |
| H2弱态回退 | 同一条件分支的弱二位counter可能不如BTFNT；请求侧只有BTB确认conditional且目标存在时才有偏移符号，指令返回侧可读当前立即数 | 无选择器状态；保留原BHT训练。13bit减法取静态方向，返回侧直接用指令符号位 | 同信息时机的纯动态/纯静态；若静态覆盖造成的新增错误更多，或面积×时间不改善，不推荐 |
| 新缩放TAGE | 短PC索引混合不同历史、alias干扰 | 借鉴Seznec的最长匹配、alternate、USE_ALT、分配/useful、折叠历史；base和tagged独立。解析训练，快照随原流水传递 | 与bimodal/gshare扩容、旧小TAGE比较；单独变化base/表数/容量/tag/长度，不以作者8KB当同成本对照 |
| SC与loop | TAGE残余偏置、规律退出 | 三个有符号小表、中心化和、动态阈值；四项稳定trip。它们与作者完整特征/age组织不同 | 同基底四组合；统计正确推翻和错误推翻。默认SC对小表并非稳定获益，不能靠更低总错误掩盖某个覆盖器的伤害 |
| 可恢复推测历史 | 解析GHR对在途分支较旧 | 接受已识别条件查询时推进；查询保留前历史，错误、漏插和错类型显式恢复。普通错误恢复退回解析副本 | 与完全相同表资源的resolved版本比较；修复额外恢复与快照成本均计费。局部early override组合尚未实现，不冒充可任意全开 |
| 早期直接目标 | BTB缺项时无法采用正确方向，JAL只能等EX | I-cache返回后精确计算B/J目标，沿现有fetch交付边界纠正，保留当前和更老指令，排空已展示旧请求 | 原BTB、BTB扩容、相同early通路的动态/静态/混合/TAGE。AXI返回至队列恢复的组合路径是实际代价，不把无额外寄存器等同无时序成本 |
| 早期RAS | 请求侧漏识别ret时已有栈顶未被使用 | 返回指令到达后按x1/x5提示识别，使用解析RAS；首次受阻保存34bit稳定性状态，正常直通不增加周期 | 单独R0、直接目标ER0、TAGE组合NER0，修复前结果不作为可交付候选。紧邻call/ret的旧栈顶仍靠EX校验 |
| LocalHistory | 每个PC自身的周期模式可能优于全局历史 | CVA6S+启发的有限行私有历史/PHT模型；不是动态组件混合，也不是H1-H4 | 16/32/128行，2/3/4bit历史，先看同预算模型误判，再决定是否值得RTL |

H1的PC身份有真实tag成本；H3训练agreement，H4只在静态/动态分歧时训练chooser。它们已有模型，没有冒称已集成RTL。
