# 实验空间与覆盖边界

所有主比较固定cache、ISA、后端和同一软件镜像。以下都是独立开关；不是将全部机制打开后只对照旧基线。实际命令、源快照和日志哈希由测量索引绑定。

| 组 | 已形成的配置 | 分离的因素 |
| --- | --- | --- |
| 起点四点 | B0、B32、T16-valid、T16B32-valid | 旧TAGE与BTB容量的交互；不是最终搜索空间 |
| 简单/混合 | B0、S、H2/H2-narrow、B64、G64、G256 | 同一条件分支纯动态/静态/弱态混合；方向表容量/历史；H1/H3/H4另有有限状态模型 |
| 新TAGE组件 | N0、NL、NS、NSL以及对应-spec四点 | 相同base/tagged/target组织，独立loop、SC和历史时机 |
| 几何 | NSmall、NBase128、模型11组、RTL全状态8组 | base、tagged容量、表数、tag宽度、长度独立；未以旧T16负结果替代新组织 |
| 目标及时性 | E0、H2E、N0E、N0B32 | 相同BTB上的直接目标计算；同方向的BTB32对照；静态/动态与TAGE都真实闭环 |
| 返回识别 | R0、ER0、NER0、NSmallER及-held修复版 | 单独RAS、早期B/J、方向算法和组合；未把全部组合收益归到TAGE |
| 诊断 | 原预测、全部顺序、未来next-PC oracle | 仿真专用，退休序列一致；oracle不参与综合/候选排名 |
| 系统敏感性 | 20/100/200ns，配对随机seed，text布局0x3f00/0xff00，独立冷/跨请求暖窗口 | 存储周期换算、总线交互、地址区域和预热，不改变cache容量 |

| 类别 | 当前证据 | 尚未覆盖 |
| --- | --- | --- |

| T1分级BTB | 快4+慢32的M0/M1诊断；追加14开发输入、三种方向、慢表1/2/3拍的有限状态模型 | 候选闭环的端口竞争及RTL；未把晚命中直接换算为加速 |
| T2直接目标 | 真RTL、静态/混合/TAGE组合、反压/恢复、PPA | 对新增长组合路径的进一步结构优化 |
| T3预译码/预填充 | 实际I$安装/回填事件驱动的类型/直接目标模型，以及四项提示队列、单空闲写口的两种预填充策略；三种方向组合 | 候选闭环RTL、独立查询端口及PPA；目前预填充负结果不代表所有准入方案 |
| T4压缩目标 | 原compact RTL范围复测；追加U16/异构宽度与fold/SRRIP/taken/TAGE的模型组合；独立2/4项高位区域表模型 | 新组合的同预算RTL/PPA、跨区实际软件压力；模型没有区域替换/范围拒绝 |

| T7提前操作数解析 | 真实RTL逐拍记录RF/RAW/前递、结构阻塞及距EX间隔 | 独立提前解析RTL及新增前递/比较路径PPA，尚不能判断净收益 |

## 不混用证据

旧real-images把校验算入ROI；real-images-v2修正边界；streams进一步改变输入/调用方式，三者分别比较。
R0/ER0/NER0初版缺少返回预测的反压保持，不作为最终安全候选；使用-held版及匹配源的PPA才有资格进入Pareto。
未得到匹配PPA的700MHz周期仅作同频诊断。最终保留集已完成，见`final-results.json`；未实现项不写成“已淘汰”或“没有价值”。

## 新补的时机与范围诊断

开发集309,676个条件分支中，249,248个在操作数首次就绪时需要现有前递。304,620个从操作数就绪到EX解析只有两拍；复制提前比较器会把前递选择加入恢复路径，且不能越过老访存/异常的顺序约束。长结构等待不等于可被提前解析全部消除，T7当前只交付机会诊断。

快4项＋慢32项目标表按B0真实查询/解析时刻重放：54,286次taken目标可由慢表修正快表；二拍返回只有22,365次早于现有fetch交付。没有用这个数字乘固定penalty估算时间，未决第一实例/替换分别记数；候选改变错误路径后的结果仍需RTL。

原布局所有已执行taken目标均同64KiB区域，不能据此确认U16适用。除两组重链接外，本轮重新运行压缩BTB原有五组定向/随机配置：每组20,065事件，显式跨32个位宽边界、迁移、拒绝与失效。它证明原范围回退行为，不证明压缩方案在新布局获益。

假设I$每条RV32I槽保存3bit类型＋1bit偏移符号，1KiB需要1,024bit旁带，若需单独valid再加256bit，尚未计立即数/端口。这是明确成本估算，未建成预译码RTL。当前early B/J实际取回指令再计算，不偷用离线反汇编信息。

2026-10-02追加的[四类目标模型](target-model-study.md)使用完整自然前缀和实际安装时刻，覆盖54组/14开发输入；计数与上面的早期10代理窗口诊断分开。新direct模型明确计入3位类型＋21位位移，不能沿用上面的仅类型/符号成本估算。
