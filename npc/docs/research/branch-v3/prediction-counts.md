# 最终保留集：方向错误与EX纠错

比较稳定BHT16/BTB16（735MHz）与NSL-BT32-fold（720MHz）：缩放TAGE＋SC＋Loop、
32项/4路BTB、折叠索引、SRRIP、新taken条件分支准入。后者未启用早期直接目标、早期RAS或推测历史。
软件与硬件配置按冻结记录；本页只补统计，不改变候选或参数。

纯方向错误数在短/长组分别减少53.00%/60.48%；条件分支EX纠错减少53.17%/62.66%；
全部控制流EX纠错减少51.66%/60.33%。时间收益仍只有各自频点短/长组3.84%/3.25%，
原因与面积代价见[取舍](decision.md)及[BTB联合探索](btb-study.md)。

口径：

- 纯方向错误：条件分支查询时的方向预测与真实taken不一致，在BTB目标可用性门控之前统计。
- 条件EX纠错：实际条件分支在EX解析交付时触发redirect；包含方向错、缺目标、目标错。
- JAL/JALR EX纠错：无条件跳转（包括返回）在EX触发redirect。日志`target_errors`采用此分类，
  不是所有指令的“目标地址错误数”；条件分支目标错仍计入条件EX纠错。
- 不应将“条件EX纠错－纯方向错误”直接归因于BTB缺项：原始方向错也可能被顺序取指掩盖。

`summarize_prediction_counts.py`校验40份日志哈希，合计完整及最后部分WINDOW，
并要求WINDOW纠错和等于冻结COUNTERS。机器结果见`final-prediction-counts.json`。

## 其他目标获取方法的实际覆盖

| 方法 | 当前实现与实验 | 边界 |
| --- | --- | --- |
| 早期直接目标 | I-cache返回B/J后识别类型并计算PC＋符号扩展立即数；结合方向，在EX前局部恢复。已有RTL、简单/混合/TAGE对照、恢复反压测试及PPA | 无额外流水级，但增加组合延迟；条件是否成立仍需预测。普通JALR依赖rs1，不能这样求目标 |
| I-cache预译码/BTB预填充 | 新增实际I$安装时刻驱动的有限metadata与提示队列模型，三种方向联合准确率，见[补测](target-model-study.md) | 尚无候选RTL和闭环性能/PPA；不得按early B/J实现冒充缓存预译码 |
| 分级BTB | 快4＋慢32，慢表1/2/3拍，分别记录初始、取指接受前与EX前的模型准确率 | 尚无闭环RTL；晚结果可用不等于已省去恢复周期 |
| BTB准入/索引/替换 | 120点模型、35点闭环RTL/PPA及验证/保留集。当前准入仅限制新表项，已有项继续更新 | 未实现退休有用性驱动的自适应BTB准入；单独taken准入曾在验证输入退化3.77% |
| 目标压缩 | 既有RTL五组各20,065次检查；追加32/64项U16/异构宽度与fold/SRRIP/taken及三种方向的有限模型 | 联合模型不是交付RTL；尚无同预算闭环/PPA，RTL入口继续拒绝该组合 |
| 共享高位区域表 | 新增独立2/4项区域表模型，保存目标低位与区域索引；索引复用先清除全部引用，有定向检查 | 尚无RTL；实际开发输入无区域替换，不能据此推断跨区域程序表现 |

压缩目标只有PC与目标高位相同时才可放入对应窄路；跨区目标可迁移至能容纳的宽路，
所有路均不能表达时拒绝分配并回退到后续纠错，不能截断后误预测。完整PC tag始终保留。
