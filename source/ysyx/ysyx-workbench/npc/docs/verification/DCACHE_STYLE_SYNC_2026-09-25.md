# D-cache 配置与 RV32 代码风格同步

后续复位、电气约束和 700 MHz 完整综合后验收已完成，见 [复位与电气修复记录](RESET_ELECTRICAL_FIX_2026-09-25.md)。本页保留当时的测量结果。

2026-09-25。目标为 `ysyx-workbench/npc` 的 RV64 单发射顺序核。
D-cache 默认改为 **256 B、2 路、16 B 行**，与 RV32 最终预设一致。
当前数据及 AXI 数据仍为 64 位，所以共有 8 组，每行 2 个数据字，回填/写回各用 2 个 beat。
I-cache 1 KiB/4 路/32 B/策略 13，BHT16、BTB16/2 路、RAS4 保持既有选择。

## 风格同步范围

- 对照源工作区，核对目标设计目录中的 62 个 HDL 文件，包含系统、仿真及已有独立实验。
- 33 个文件在工程前缀/模块名称适配后复用源文件；两处无效的源中断字段赋值按目标类型去除。
  复制前比较注释外的词法标记，确认逻辑与原 RV64 实现一致。
- 单拍事件统一为 `*_event`；握手使用 `*_handshake`；保存的事件历史继续使用 `*_occurred_q`。
  操作数选择字段使用完整的 `operand_a_select`、`operand_b_select`，测试和调试引用同步修改。
- 条件与赋值分行，case 标签与分支体分行，保持列对齐及续行缩进。格式化前后词法标记一致。
- 寄存器堆组合读口移到写入更新之前；CSR 输出连接移到更新之前。仅移动独立连续赋值，
  原有异常、mret、CSR 写入优先级保留。
- 目标 RV64 CSR、中断尚未接通的边界、FENCE.I 失败重试、64→32 位平台转换继续保留。
  源分支的实验预测器及平台功能不作为风格变更复制进来。

当前规范同步加入寄存器、等待与旁路检查，避免后续修改重新引入不必要的等待或重复状态。
没有删除历史、实验或未参与当前构建的源码，也没有执行 Git 提交或合并。

## 面积和时序

使用 Nangate45 typical 库，以 `riscv_core` 为顶层，采用与 RV32 相同的 `AREA 3` 策略、
820 MHz 映射目标，再对固定网表做 700 MHz STA。映射目标不是通过验证的运行频率。
本轮测量不包含完整系统和复位释放边界，未进行布局布线、时钟树构建或功耗分析。

| 项目 | 本轮结果 |
| --- | --- |
| 映射标准单元面积 | **123,162.788 µm²** |
| 700 MHz setup WNS / TNS | **+0.030 ns / 0 ns** |
| 700 MHz min 组 WNS / TNS | **−0.021 ns / −22.786 ns** |
| 时钟门控 setup / hold 最差裕量 | +0.064 ns / +0.097 ns |
| 电气约束 | 存在最大电容、最大转换时间违例；fanout 限值显示 NA |
| 完整时序验收 | **未通过** |

最差 setup 路径由执行级寄存器经过访存请求逻辑到数据 AXI `ar_valid` 输出；
当前裕量只有 30 ps。min 组最差路径是 `rst_ni` 到 IFU 预测 PC 寄存器 `RN` 的
**复位 removal 检查**，不能把它误写成普通数据保持路径。现有 SDC 虽设置了复位 false path，
报告仍列出该检查，应核对实际复位释放边界和工具对约束的处理，不能忽略负裕量。

电气报告中，门控时钟输出电容的最差报告裕量为 −0.346 pF；I-cache 暂存回填数据驱动
数据阵列时，最大转换时间裕量为 −0.340 ns，也有电容违例。下一步应针对实际负载检查
缓冲、数据写入分组及门控时钟驱动，并连同复位释放重新验收 setup、min 和电气约束。

本次 STA 使用理想时钟，输入/输出延迟为周期的 20%，输入转换时间为 0.1 ns，
没有显式输出负载或布局寄生参数。因此只能说明**当前条件下 700 MHz 的 setup 检查通过**，
不能声明整核已经完整达到 700 MHz。

[上轮记录](RV64_BYPASS_SYNC_2026-09-24.md) 的 4 KiB 配置面积为 350,962.262 µm²，
但使用 `DELAY 0`、300 MHz 综合。本轮面积明显下降，差值同时包含缓存配置和映射策略变化，
不能全部归因于缓存缩小或代码排版。RV32 的完整复位边界结果也不能与本轮纯核结果混用。
