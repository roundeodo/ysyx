# 本设计的修改约定

本目录包含 NPC 的处理器、系统连接、仿真环境和独立实验。设计名称不绑定整数位宽。

修改前阅读 [RTL 编码规范](../../docs/development/NAMING_GUIDE.md) 和
[设计模块总览](../../docs/architecture/RTL_MODULE_MAP.md)，再阅读对应模块的设计记录。

- 名称说明当前硬件含义；区分状态、事件、位集合、数组和索引。
- 按功能把声明、辅助计算、组合逻辑与寄存器更新放近。
- 三段式状态机依次排列输出、下一值和时序更新；纯组合模块与简单寄存级不强加状态机。
- 注释和教学 TODO 紧邻实际代码位置；维护列对齐与续行缩进。
- 重命名同步更新端口连接、类型、断言、调试引用、构建入口和当前文档。
- 根据实际改动运行相关检查，并如实记录失败项。不能把局部测试通过写成整核验证完成。

具体定义以编码规范为准；发现文档与实现不一致时，先核对事实，再同步修改说明。
